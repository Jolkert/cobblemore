# Cobblemore
Cobblemon is missing a few competitive items. This mod addresses that.
Its unfinished and ugly, as the sprites are just resized sprites from bulbapedia

## What does it add?
Cobblemore adds many held items that aren't present in base Cobblemon including:
- Eject Pack
- Terrain Extender
- Misty/Electric/Grassy/Psychic Seed
- Metronome
- Wide/Scope/Zoom Lens
- Throat Spray
- Room Service
- Protective Pads
- Utility Umbrella
- Shed Shell


The only item without any means of obtaining in survival in the current version is the Shed Shell
